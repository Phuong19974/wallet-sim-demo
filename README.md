# Degen Wallet (demo)

This is a **spot-trading wallet simulator** for UI demos. It is **not a real wallet**.

- Market prices are fetched from public Binance tickers (`BTCUSDT`, `ETHUSDT`, `SOLUSDT`, `BNBUSDT`, `LINKUSDT`, `XRPUSDT`, `ADAUSDT`, `USDCUSDT`).
- All balances, swaps, sends, and activity are **simulated data** stored only in your browser (`localStorage`).
- It cannot hold, send, or receive real funds.
- There is no seed phrase or private key field. Do not enter real secrets.

Live demo: https://phuong19974.github.io/wallet-sim-demo/
